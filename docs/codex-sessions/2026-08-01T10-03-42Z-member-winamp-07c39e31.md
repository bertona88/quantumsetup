````text
### 6. Render multiple temporal slices simultaneously

The visual is not a picture of `now`. Sample the same world at several temporal offsets:

```js
const slices = [
  sampleWorld(now - 2.0), // residue

```

Then interfere those slices rather than displaying them separately:

```js
pixel = interfere(slices, field.phaseTexture);
```

That creates the ambiguity we want: viewers cannot tell whether a structure is remembered or imminent.

### 7. Let the automaton participate carefully

if (world.accumulatedTension > 0.8) {

```

The automaton does not directly synthesize arbitrary notes. It participates in musical decision-making while the existing grammar retains rhythmic and sonic quality control.

### 8. The audiovisual clock

Everything must use the Web Audio clock:

```js
const now = audioContext.currentTime;
world.advanceTo(now);
visual.render(now);
```

`requestAnimationFrame` only determines when we draw. It must never define musical or simulation time. If rendering drops frames, we reconstruct the correct world state from the audio clock and deterministic coordinates.

### 9. The opening

Before play, the simulation can already render its timeless structure using a frozen virtual clock. Pressing play should:

```js
world.attachAudiblePlane(audioContext.currentTime);
```

It doesn’t create the world. It begins moving the listener’s audible plane through it.
````
